# Support

Support for Mori happens in the open, on GitHub.

- **A bug, or something that does not work as documented:** open an issue in
  the repository it belongs to, with the steps that show it.
- **A question or an idea:** open an issue and describe the problem behind it.
- **A security problem:** never in an issue. Follow the
  [security policy](SECURITY.md).

Issues are public. Leave out personal data, private records, tokens, and file
paths you would not publish.
