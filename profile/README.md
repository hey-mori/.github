# Mori

Local-first desktop tools for keeping track of your own work and for reading
across languages. Your data stays on your computer.

Mori is a working name, and every project here is in early development. None
has a published release yet. Each repository says what works today and how to
build it.

| Project | What it does |
| --- | --- |
| [Mori](https://github.com/hey-mori/mori) | A personal context workspace. It turns AI agent sessions, Git history, notes and links into a record of what you did, learned and decided. |
| [Mori Lens](https://github.com/hey-mori/mori-lens) | A reading assistant. Rest the pointer on text in any application and see it explained in your language by a local model. Windows first. |
| [Mori Browser Extension](https://github.com/hey-mori/mori-browser-extension) | An opt-in Chromium extension that tells the Mori app which page is active. |
| [mori-web](https://github.com/hey-mori/mori-web) | The product website. Not deployed yet. |

Mori and Mori Lens are separate products with no shared code or runtime
dependency. Both keep what they read on your machine: Mori contacts an AI
provider only when you grant one, and Lens talks only to a model running
locally.

- **Contributing:** read the
  [contributing guide](https://github.com/hey-mori/.github/blob/main/CONTRIBUTING.md).
  The code is licensed under MPL-2.0, and commits from outside the
  organization carry a sign-off.
- **Security:** report privately under the affected repository's *Security*
  tab, never in an issue. See the
  [security policy](https://github.com/hey-mori/.github/blob/main/SECURITY.md).
