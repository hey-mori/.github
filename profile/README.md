## Mori

일상의 작업 흔적을 사용자의 기기 안에서 서로 연결된 기록으로 정리하는
로컬-first 개인 컨텍스트 워크스페이스를 만듭니다.

- **로컬 우선.** 데이터는 사용자의 기기에 머무르며, 기본으로 켜지는 클라우드 동기화는 없습니다.
- **숨은 수집 없음.** 사용자가 연결한 출처만 읽습니다.
- **출처를 남깁니다.** 정리된 기록은 어디에서 왔는지 언제든 확인할 수 있습니다.
- **상태를 정직하게.** 지금 동작하는 것과 계획 중인 것을 구분해서 말합니다.

현재 비공개로 개발 중이며, 아직 공개된 릴리스는 없습니다.

---

Mori is a local-first personal context workspace. It turns everyday traces of
work into connected records, on the user's own device.

- **Local-first.** Data stays on the device. There is no cloud sync by default.
- **No hidden capture.** Mori reads only the sources the user connects.
- **Origin stays visible.** Every organized record can be traced to where it
  came from.
- **Honest status.** We say what works today and what is still planned.

Mori is in private development. There is no public release yet.
